AI Context Package

A compact, LLM-friendly version of the Thruness brand guidelines. Drop it into a system prompt, project context window or RAG store so any AI assistant can write, design and build for Thruness without going off-brand.

Download the full pack

thruness-brand-all.md — every section in a single 20KB markdown file. Paste it into Claude, ChatGPT, Cursor or any other AI tool as context.

How to use
1
Cursor / Claude Code project rules
Copy the contents of thruness-brand-all.md into a project rules file at .cursor/rules/thruness-brand.md or AGENTS.md. The assistant will read it on every turn.
2
Custom GPT / Claude Project
Upload all the numbered files. The assistant retrieves the right one for each question — type questions hit typography, voice questions hit tone-of-voice, and so on.
3
One-off prompts
If you only need help with one task, paste only the relevant file (e.g. just 06-tone-of-voice.md when writing copy).
4
RAG / vector store
Index the individual files. Each one is small enough to fit comfortably in a single chunk, and the structured markdown makes for clean retrieval.
Suggested system prompt

If you're wiring this into a custom assistant, lead with something like:

You are a brand-aware assistant for Thruness — a voice-first gait
tracking app for equestrians. Read the brand guidelines below before
responding. Apply the tone of voice (honest, quiet, knowing, reverent),
use the type system (Philosopher Regular + PT Sans), the colour palette,
the icon library (Lucide, stroke 2), and the UI patterns described.

UK English. No exclamation marks. No emoji in UI. Voice prompts under
six words. Horse is he / she / they — never "it".

Keeping the pack fresh

The markdown files live alongside the rest of the brand guidelines in the salocreative/thruness repo, in the /ai-context/ folder. When the brand evolves, the files are updated there first, then re-distributed. Pin a specific commit if you need a stable reference.
