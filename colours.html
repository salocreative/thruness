Shade usage

Light — badge backgrounds, chart fills, subtle highlights. Base — gait bars, live indicators, primary UI swatches. Dark — hover/active states, borders, legend labels on light surfaces.

Why these colours

The previous green-only scale was too close in hue for small UI elements. This set spreads gaits across grey → blue → green → amber → purple so each reads distinctly in a bar, badge or live indicator — including for riders with colour vision deficiency, where hue difference matters more than shade alone.
